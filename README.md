## 为什么是洛杉矶，为什么是 CN2 GIA

先说线路，因为这是整个选择的根基。

中国电信到美国的 IP 出口大致分几档：最普通的是 AS4134（163 网），便宜但晚高峰丢包能到 30% 以上，开会卡、网页转圈；往上一档是 CN2 GT（AS4809），本来是想解决拥堵，但 2019 年之后和 163 区别越来越小；再往上才是 **CN2 GIA（AS4809 Global Internet Access）**，这是电信目前最贵也最稳的商业级回程，搬瓦工官网直接说明：CN2 GIA 单兆 transit 成本能到 \$120，1Gbps 满载一个月账单理论上能到十万美元级。贵是真的贵，但稳也是真的稳。

搬瓦工在洛杉矶的 CN2 GIA 节点目前有两个主力机房：

- **DC6 CN2 GIA-E**：搬瓦工自己主推的"电商版"机房，回程走 CN2 GIA，带宽 2.5Gbps 起，是绝大多数人选的那一档。
- **DC9 CN2 GIA**：和 DC6 同系列，可作为备选或迁移目标，同样走 GIA 回程。

另外还有一个较新的 **DC5 SLA 机房**（USCA_9），主打三网 premium：电信 CN2 GIA + 移动 CMIN2（AS58807）+ 联通 premium（AS10099），并附带 99.99% SLA 保证。这个机房定位比 GIA-E 更高一档，价格也更高，适合对稳定性要求更苛刻的外贸/企业建站。
